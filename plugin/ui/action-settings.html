Social Stream Ninja

Collect live chat from multiple platforms and control overlays, queues, polls, docks, and SSApp sources from Stream Deck keys.

Enter a Social Stream Ninja session ID.
Use the same session ID as your Social Stream dock, overlay, or desktop app.

Setup Guide

1
Open Social Stream Ninja
Run the browser version or the SSApp desktop app before using Stream Deck actions.
2
Paste your session ID
This is the private ID used in URLs such as dock.html?session=....
3
Test the connection
The status key turns online when the Social Stream API socket joins your session.
4
Choose an action
Start with a preset command, then use Custom Command only for advanced payloads.

Connection

Advanced connection settings
Default Stream Deck remote control sends on channel 1 and listens for callbacks on channel 2.
SSApp source controls unavailable until capabilities are received.

Status Key

Leave blank to let the key show Setup, Connecting, Online, or Offline.

Preset Command

Preset commands use the documented Social Stream remote-control API.

Custom Command
