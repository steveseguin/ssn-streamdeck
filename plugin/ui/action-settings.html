Preset Command

In Event Flow, add Run from Stream Deck / API, give it a trigger name, then save and enable the flow. A check mark means the run was accepted; delayed and external actions may still be running.

Preset commands use the documented Social Stream Ninja remote-control API.

Custom Command

Custom Command is for payloads not yet exposed as presets.

Timer Dial

Turn one click to add or subtract the configured seconds. Hold the dial down while turning for 6× the step (default: 1 minute). Press and release without turning to start/pause. Tap the timer display to refresh; hold that display to reset.
Timer gestures and examples

Chat Review

Turn left for older chat, right for newer chat. Press the dial to pin the displayed message. Tap its display to feature the next pinned message; hold the display to unpin the reviewed message. Keep Social Stream Ninja and the default dock open.
